# プロトタイプ v5: 骨組みから違う12案（01〜12）（2026-11-12・Issue #9）

v4 の10案は本人に「どれも同じかんじ。AI感がすごい」と言われた。本人の追加の言葉は「インストールしていいから様々なタイプを。10案くらい。Webサイトそのもののような作りも」「あとは単純にゲームとか」。

- 開き方: `file:///C:/Users/3fort/dev/github-ranking/prototype/v5/index.html`
- 返事は「好きな番号・嫌いな番号」

## v4 から変えたこと（なぜ外れたかへの対策）
| v4 の原因 | v5 でやったこと |
|---|---|
| 全案が同じ骨組み（見出し→日付3ボタン→概況→1位→一覧）で色と書体の着せ替え | 案ごとにそのジャンルの画面の作りそのもの（RPG のウィンドウ、掲示板のレス、OS のデスクトップ…）。共通の型を禁止 |
| 実物の画面を見ずに作った | 作る前に実物を撮って「本物らしさの正体」を書き出した（撮れなかった案は下に明記） |
| 本物の素材が0（四角と幾何学の SVG） | 各案に素材を入れた（自作のドット絵・98.css・ドットフォント等）。出典とライセンスは各案の `assets/CREDITS.md` |
| 定番の Google Fonts | v4 で使った書体を禁止。DotGothic16・Yusei Magic・Mochiy Pop One・BIZ UDPGothic・OS の MS P ゴシックなど |
| 全行に全情報を同じ密度で | ジャンルの密度に合わせた（掲示板・通販・ポータルは詰める、ノベルは1件ずつ） |

## 作り方
- 共通の指示書（禁止事項・手順・素材のライセンスの確認）を1つ書き、2案ずつ6つの Sonnet サブエージェントで作った。途中で5時間の使用量の上限に達して止まり、上限が戻ってから続きを作った
- 私の確認: 12案を PC（1280px を縮小）とスマホ（390px）で撮って見た。12案とも JS の例外 0（Chrome headless の記録）。390px の横はみ出しは各エージェントの検査で 375〜390（はみ出しなし）
- 検査用の URL の指定（`?sim=`・`?auto=`・`?open=`・`?diag` など）が一部の案に残っている。使い捨てなので本番化のときは使わない
