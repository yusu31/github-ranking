github-ranking プロトタイプ v3 — 見やすさ優先の4案（E〜H）＋前回の4案（A〜D）

今回は、ゲーム・マンガアプリ・天気サイトなど本物の画面を撮って見てから作りました。どの案も「1件ずつ顔（アイコン・表紙）がある」「数字と上下の印で一瞬で分かる」を土台にし、そのうえで見た目を変えています。アイコンは仮の模様で、本番は持ち主の本物のアバターになります。

返事は 「好きな番号・嫌いな番号」 だけで大丈夫です（例: 好き E・G／嫌い A）。「この案のここだけ好き」も歓迎です。
表示の幅: 移動: EFGH｜前回:ABCD

どの案も同じ仮データ（すべて架空）。中の画面は触れます（日付の切り替え・お気に入り・行を押すと★の推移）。「更新が止まった日」の見え方は、各案を全画面で開いて URL の末尾に ?state=stale を付けると見られます。

v3 の決め方・参考にした実物の画面は prototype/v3/README.md、前回（v2）は prototype/v2/README.md。
