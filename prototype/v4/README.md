## 作り方
- 共通の指示書（機能・AI感の禁止事項・確かめ方）を1つ書き、2案ずつ5つのサブエージェント（Sonnet）に並行で作らせた。各自が Chrome headless で撮って1回以上直した
- その後、私が10案を PC（1280px）・スマホ（390px）で撮って見た。機械でも検査した: 10案とも JS の例外 0、390px で横はみ出しなし、説明の HTML 混入から `<img>`・`<script>` が作られた数 0、「null」「undefined」の表示 0
- 既存サービスの調査（Obsidian `Projects/github-ranking/2026-11-12_既存のGitHubランキング調査.md`）から取り込んだもの: 今日の概況1文（計算で作る）、初登場／再登場・連続登場日数、殿堂入り（1か所）、更新時刻の JST 明示
- 特定の作品・会社の名前やロゴは使っていない。借りたのは手法だけ

## 直したこと
- 仮データの Trending の一覧が25件ちょうどで、毎日同じ顔ぶれになり「新顔」が一度も出なかった → 一覧を29件にして毎日25件を選ぶ形にした（`../v2/shared/data.js`。HTML 混入の見本は毎日必ず入れる）。**v2・v3 の画面も同じデータを使うので、並びが変わる**
- L: 1位の名前が単語の途中で折れていた → 持ち主名と名前を2行に分けた

## まだ弱い点（各案を作ったエージェントの報告と私の確認）
- 連続登場日数・初登場／再登場・殿堂入りは仮の値（名前から計算）。本番は記録から出す
- I は PC で 760px の1列なので左右が空く。J の1位カードは PC で右の文字欄が余る
- N はスマホのタイルに名前が無い（アイコンと順位だけ）
- O はスマホで行の右側が2段に折れて少し窮屈。P はスマホで要約が4行を超えると切れる
- Q は PC では枠ごとスクロールするので、下の固定バーが画面下に留まらない。「次回更新まで」は今の時刻から計算している
- 動き（スライド・スタンプ・箔の光）は静止画の撮影では見られない。コードはあるが、動く様子は人がブラウザで見て確かめる
