# プロトタイプ v2: まるで違う4案（2026-11-12・Issue #9）

v1「星の朝刊」（新聞風）は本人が不採用（「ダサすぎる・好みではない」）。今回はリサーチのあとに、**互いに何も被らない4案**を同じ仮データで作り、`index.html` の1ページで見比べる。

- 開き方: `prototype/v2/index.html` をブラウザで開く（サーバー不要。フォントだけ Google Fonts から読む）
- 各案は単独でも開ける: `a/index.html` 〜 `d/index.html`
- 仮データは v1 と同じ（`shared/data.js` は v1 の `data.js` の複製）。リポジトリ名・数値はすべて架空
- 状態の見本: URL の末尾に `?state=stale` を付けると「更新が止まっています」の表示になる（本番には無い切り替え）

## 4案の決め方
1. 本人の taste（design-review スキル）: 寄せる＝実在の文法・署名の動きは1本・入力に即反応・淡い発光／避ける＝紫→ピンク・意味のないガラス・同型3カラム
2. リサーチ3本（人気の雰囲気・ランキング系の構成・「AI感」の正体）
3. AI議論モード（リサーチャー・CD・エンジニア・批評家）で4つに絞る
4. **どの案も「実在する物の構造」を1つ借りる**（AI感の対策: 題材に固有の文法を使い、初期値の見た目を使わない）

| 案 | 借りる実物 | 色 | 書体 | 構成 | 署名の動き（1本） | 本番の重さ |
|---|---|---|---|---|---|---|
| A | 駅の LED 発車標 | 黒＋橙・緑・赤の LED（発光は淡く） | DotGothic16 | 横長の掲示板。1〜3位を「先発・次発・次々発」 | 要約が日本語⇄英語で切り替わる（実物の発車標の交互表示） | 軽い |
| B | スイスの組版（国際タイポグラフィ様式） | 白と黒だけ（色を使わない） | Archivo＋Zen Kaku Gothic New | 左右非対称の格子・巨大な順位の数字・罫線 | 行に触れると★の推移の線が描かれる | 軽い |
| C | データ報道（The Pudding 型） | トマト色・ミントの色面 | Bricolage Grotesque＋Zen Maru Gothic＋Yomogi（手書き） | 散布図が主役・手書きの注記・その下に一覧 | 日付を変えると点が新しい位置へ動く | 重め（グラフ） |

## 却下した方向（理由）
- ターミナル・CLI 風: A と「黒＋等幅」で被る。緑×黒は量産されやすい
- ブルータリズム: 本人の「ダサいのは NG」に触れやすい。B（スイス）で「強い組版」の役は足りる
- アーカイブ・図書館カタログ: セリフ体と生成りに寄りやすく、却下された新聞案に近づく
- レトロ OS・Y2K: 毎朝読むには窓の操作が邪魔
- 地図・天気図: GitHub のリポジトリに地理が無く、構造が嘘になる
- ダッシュボード風のカード格子: 既存サービスと見分けがつかず、AI感の代表（KPI カード4つ・同形カード）

## 全案で共通に避けたもの（AI感の一覧より）
