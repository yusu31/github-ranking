## 設定

`.harness.json` に merge の方針・guard の強さ・学習モードがある。**変更できるのは本人だけ**（AI は書き換えない）。
自分だけの指示（ローカルのパスなど）は `CLAUDE.local.md` に書く。Git 管理外（`.gitignore` 済み）なので共有されない。
GitHub 側の設定は [docs/ruleset.md](docs/ruleset.md) を参照。
