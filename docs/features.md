# 機能一覧: github-ranking

ID の付け方: 機能 `F-01`、受け入れ条件 `AC-01`、ユースケース `UC-01`、テスト `T-01`。
F-01〜F-07 は requirements.md §1 の①〜⑦と同じ順。F-08 は①〜⑤を毎朝動かして見せる土台（§1 の概要「公開ページと日報にする」）。

> **Phase 1 のたたき台（2026-11-12）。** 数値のうち【確認】の印があるものは、本人の承認で決まる。【Phase 3】は基本設計で実際に確かめてから決める。

## ユースケース
- **UC-01**: 本人が朝、Obsidian の日報（またはスマホでページ）を開き、Trending と関心領域の上位を日本語の1行要約で数分で眺める（F-01〜F-05・F-08）
- **UC-02**: 本人が気になったものに☆を付け、週に1回まとめて Obsidian に送る（F-06・F-07）
- **UC-03**: 公開ページを見た開発者・採用側が、ログインなしで当日と過去の日の一覧を見る（F-08）
- **UC-04**: 更新が止まったとき、本人がページの表示で気づき、runbook の手順で戻す（F-08・§10 の R-01）
